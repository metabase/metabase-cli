# Changelog

Notable changes to `@metabase/client`.

The package is workspace-internal (`private: true`) and reaches no registry, so it carries no
released versions. `@metabase/cli` inlines it at build time, and the CLI's own release notes are what
a user of the CLI reads. Entries here accumulate against the first published release.

## Unreleased

The whole surface. Until a first release there is no baseline to diff against, so a change to this
package is recorded in its commit rather than here.
