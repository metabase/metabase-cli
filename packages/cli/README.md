# @metabase/cli

Command-line client for Metabase — the `mb` binary.

```sh
npm install -g @metabase/cli
mb --help
```

Authentication, output flags and environment variables are documented at
<https://github.com/metabase/metabase-cli#readme>, and every command at
<https://www.metabase.com/docs/latest/cli/>. The same pages ship in this package under `dist/reference/`.
