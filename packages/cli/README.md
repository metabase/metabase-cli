# @metabase/cli

Command-line client for building Metabase content as YAML files: the `mb` binary. It reads warehouse metadata (`mb metadata`), validates representation files (`mb check`), and saves a git repository into Metabase (`mb save`).

```sh
npm install -g @metabase/cli
mb --help
```

Commands, authentication, output flags and environment variables are documented at
<https://github.com/metabase/mb-cli#readme>.
